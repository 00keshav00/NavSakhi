# SafeShe Services & Utilities

This document outlines the core business logic services, utility helpers, and middleware deployed in the backend application.

## 1. Domain Services (`app/services`)

### `JourneyService`
- **File**: `app/services/journey_service.py`
- **Purpose**: Manages the lifecycle of a Journey. Handles CRUD operations, state transitions (Planning -> Active -> Completed), and data normalization before delegating complex intelligence gathering to the Coordinator.
- **Functions**:
  - `create_journey(user_id, data)`: Persists initial journey intent and fetches the AI plan.
  - `start_journey(journey_id)`: Mutates state to ACTIVE.
  - `_active_monitor_loop()`: (Background Task) Simulates WebSocket-like live telemetry updates.
- **Imported By**: `app/api/v1/journeys.py`
- **Dependencies**: `JourneyRepository`, `JourneyIntelligenceCoordinator`, `JourneyStateEnum`

### `AuthService` (Stubbed)
- **File**: `app/services/auth_service.py` (Referenced)
- **Purpose**: JWT generation, user validation, and session management.
- **Dependencies**: `passlib`, `jose`

## 2. Intelligence Utilities & Builders (`app/intelligence`)

### `ResponseBuilder`
- **File**: `app/intelligence/response/builder.py`
- **Purpose**: A strict serialization utility that takes heterogeneous output from the Agent Pipeline (Routing data, ML scores, LLM text) and maps it precisely into Pydantic DTOs required by the frontend API contract.
- **Functions**:
  - `build_journey_plan()`: Parses pipeline output into a `JourneyPlanResponse`. Ensures the true database `journey_id` is propagated to the client.
  - `build_dashboard_overview()`: Maps system telemetry into a `DashboardOverviewResponse`.
- **Imported By**: `app/intelligence/journey/coordinator.py`
- **Used In**: Every orchestration endpoint.

### `DataNormalizer`
- **File**: `app/ml/features.py` (Implied/Referenced)
- **Purpose**: Cleans raw agent data and prepares it for feature engineering. Extracts latency metrics and risk keywords.

### `DecisionEngine`
- **File**: `app/intelligence/decision/engine.py`
- **Purpose**: Evaluates risk tolerance and finalizes go/no-go decisions based on ML predictions.

## 3. WebSockets & Middleware

### `JourneyConnectionManager`
- **File**: `app/api/websockets/journey_ws.py`
- **Purpose**: Manages active WebSocket connections for live tracking. Handles connection, disconnection, and targeted broadcasting to specific journey streams.
- **Functions**:
  - `connect(websocket, journey_id)`
  - `disconnect(journey_id)`
  - `broadcast_update(journey_id, data)`

### `CORSMiddleware`
- **File**: `app/main.py`
- **Purpose**: Security middleware enabling cross-origin requests from the React frontend (`http://localhost:3000`).

## 4. API Handlers & Dependencies

### `register_exception_handlers`
- **File**: `app/api/handlers.py`
- **Purpose**: Intercepts generic Python exceptions, Pydantic ValidationErrors, and FastAPI HTTPExceptions to return them wrapped in the standard `StandardResponse(success=False, error=...)` envelope.
- **Imported By**: `app/main.py`

### `get_current_user_id`
- **File**: `app/api/dependencies.py`
- **Purpose**: Dependency Injection utility that intercepts incoming requests, parses the `Authorization: Bearer <token>` header, validates the JWT, and extracts the User ID.
- **Used In**: Almost every authenticated route in `app/api/v1/`.
