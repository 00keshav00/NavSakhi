# SafeShe API Reference

This document outlines every backend endpoint exposed by the SafeShe FastAPI backend under the `/api/v1` namespace.

---

## 1. Journeys

### Create Journey
- **Method**: `POST`
- **Route**: `/api/v1/journeys/`
- **Purpose**: Initializes a new active journey, computes route geometry, evaluates ML safety scores, and returns a detailed `JourneyPlanResponse`.
- **Request Body**: `JourneyCreate` (source: str, destination: str, transport_mode: str, preferences: dict)
- **Response**: `StandardResponse[JourneyPlanResponse]`
- **Headers**: `Authorization: Bearer <token>`
- **Authentication**: `Depends(get_current_user_id)`
- **Validation**: Strict Enum parsing for `TransportMode`.
- **Business Logic**: Invokes the `JourneyIntelligenceCoordinator` pipeline.
- **Service Called**: `JourneyService.create_journey()`
- **Repository Called**: `JourneyRepository.create()`
- **Database Tables**: `journeys`
- **Possible Errors**: `422 Unprocessable Content` (Invalid transport mode or missing coordinates).
- **Frontend Components Using This**: `MapControls.tsx`, `JourneyService.ts`.

### Monitor Journey (Polling Fallback)
- **Method**: `GET`
- **Route**: `/api/v1/journeys/{journey_id}/monitor`
- **Purpose**: Returns live AI telemetry, safety scores, weather context, and route geometry for an active journey.
- **Response**: `StandardResponse[Any]` (Maps to `LiveMonitorResponse`)
- **Headers**: `Authorization: Bearer <token>`
- **Authentication**: `Depends(get_current_user_id)`
- **Business Logic**: Returns aggregated AI insights and coordinates.
- **Frontend Components Using This**: `JourneyMonitor.tsx`, `LiveMonitorService.ts`.

### Start Journey
- **Method**: `POST`
- **Route**: `/api/v1/journeys/{journey_id}/start`
- **Purpose**: Transitions a planned journey into an active state.
- **Response**: `StandardResponse[JourneyResponse]`
- **Authentication**: `Depends(get_current_user_id)`
- **Service Called**: `JourneyService.start_journey()`
- **Repository Called**: `JourneyRepository.update()`

*(Similarly implemented: `/pause`, `/resume`, `/complete`, `/cancel`, `/reroute`)*

## 2. Community

### Submit Community Report
- **Method**: `POST`
- **Route**: `/api/v1/community/`
- **Purpose**: Allows users to report local anomalies (e.g., broken streetlights, unsafe areas).
- **Request Body**: `CommunityReportCreate` (location, incident_type, severity, description)
- **Response**: `StandardResponse[CommunityReportResponse]`
- **Status Codes**: `201 Created` on success, `422` on validation error.
- **Authentication**: `Depends(get_current_user_id)`
- **Database Tables**: `community_reports`
- **Frontend Components Using This**: `ReportAnomalyModal.tsx`, `CommunityService.ts`.

### Get Community Heatmap
- **Method**: `GET`
- **Route**: `/api/v1/community/heatmap`
- **Purpose**: Returns GeoJSON features representing reported dangers to render on the MapLibre component.
- **Response**: `StandardResponse[GeoJSONFeatureCollection]`

## 3. Profile & Settings

### Get User Profile
- **Method**: `GET`
- **Route**: `/api/v1/profile/`
- **Purpose**: Fetches the authenticated user's profile details and preferences.
- **Response**: `StandardResponse[UserProfileResponse]`
- **Status Codes**: `200 OK`
- **Authentication**: `Depends(get_current_user_id)`
- **Database Tables**: `profiles`
- **Frontend Components Using This**: `ProfilePage.tsx`

### Get User Settings
- **Method**: `GET`
- **Route**: `/api/v1/settings/`
- **Purpose**: Fetches application settings for the user (notifications, privacy).
- **Response**: `StandardResponse[UserSettingsResponse]`

---

## 4. Dashboard

### Get Dashboard Overview
- **Method**: `GET`
- **Route**: `/api/v1/dashboard/overview`
- **Purpose**: Returns aggregate system health, safety scores, weather status, and community activity for the main landing dashboard.
- **Response**: `StandardResponse[DashboardOverviewResponse]`
- **Status Codes**: `200 OK`
- **Authentication**: `Depends(get_current_user_id)`
- **Business Logic**: Aggregates data via the AI Dashboard Coordinator pipeline.
- **Frontend Components Using This**: `DashboardView.tsx`

---

## 5. WebSockets (Live Telemetry)

### Journey Live Tracker
- **Protocol**: `ws://` or `wss://`
- **Route**: `/api/v1/ws/journey/{journey_id}`
- **Purpose**: Provides a persistent bi-directional connection for streaming live GPS coordinates and AI alerts during a journey.
- **Authentication**: Token passed as a query parameter or connection payload.

### Emergency SOS Stream
- **Protocol**: `ws://` or `wss://`
- **Route**: `/api/v1/ws/emergency/`
- **Purpose**: Dedicated high-priority socket for initiating an SOS distress signal and streaming audio/video telemetry.
