# SafeShe Known Issues & Technical Debt

This document catalogs existing bugs, incomplete features, architecture smells, and temporary workarounds discovered during the codebase audit.

## 1. Missing Implementations & Stubs
- **Authentication Service (`app/services/auth_service.py`)**: 
  - JWT integration is stubbed in the routes and dependencies, but full OAuth2 / bcrypt login flows are incomplete.
- **Machine Learning Predictor (`app/ml/predictor.py`)**: 
  - Uses `DummyMLPredictor`. Real `.pkl` integration is pending Phase 3.
- **Language Model (`app/tools/specialized/reasoning_tool.py`)**: 
  - Uses `DummyLLM`. True OpenAI/Anthropic SDK implementation is pending.
- **Reroute Endpoint**: 
  - `POST /api/v1/journeys/{id}/reroute` is stubbed in `app/api/v1/journeys.py` and simply returns the current journey without actively recalculating paths.

## 2. Temporary Workarounds
- **Enum PyMongo Serialization**:
  - Enums (`TransportMode`, `JourneyStateEnum`) inherit from `str` and `Enum`. This is a PyMongo compatibility workaround required to avoid `bson.errors.InvalidDocument` without writing custom `bson.codec_options`.
- **Frontend / Backend Enum Mismatch**:
  - The frontend natively sends `"walking"` while the backend expects `"WALK"`. A mapping dictionary was implemented in `JourneyService.create_journey` as a workaround rather than rewriting frontend types.

## 3. Architecture Smells
- **Coordinator Monolith**:
  - The `JourneyIntelligenceCoordinator` (`app/intelligence/journey/coordinator.py`) orchestrates *everything*. While it utilizes topological workflows, the class is highly bloated and acts as a god-object for the intelligence layer.
- **Polling over WebSockets**:
  - The `LiveMonitorService.ts` currently defaults to polling `/api/v1/journeys/{id}/monitor` because the WebSocket implementation (`/api/v1/ws/journey`) is incomplete on the client-side UI.

## 4. Unused Files & Dead Code
- **Stale Service Code**: 
  - Remnants of defunct orchestrations (e.g., `self.coordinator.plan_journey`) were previously left in `JourneyService` but were recently expunged. No major dead code detected currently.

## 5. Potential Bugs
- **UUID Fallbacks**: 
  - Earlier revisions of `ResponseBuilder.build_journey_plan()` hard-coded mock UUIDs (`j_dc1...`) rather than propagating the true MongoDB `_id`. This was fixed during the Phase 2.5 audit, but careful regression testing is required if builders are modified again.
- **Terminal Execution Permissions**: 
  - The local development environment restricted PowerShell/CLI execution due to `NUL ACL write: Access is denied` bugs. Python diagnostics currently rely on FastAPI Startup hooks (`auto_audit.py`).
