# SafeShe TODO & Feature Roadmap

This document outlines the implementation status and roadmap for SafeShe's features.

## 1. Completed
- **Architecture Migration (Phase 2)**: Re-structured `JourneyIntelligenceCoordinator` and decoupled `JourneyService`.
- **API Stabilization (Phase 2.5)**: Resolved PyMongo `InvalidDocument` serialization bugs and 500 internal server errors.
- **Frontend / Backend Route Alignment**: `api/v1/journeys/` matches `LiveMonitorService.ts` exactly.
- **Auto-Audit CI Simulation**: Created `auto_audit.py` to recursively test API contract boundaries during FastApi startup.

## 2. In Progress
- **Documentation Engine Generation**: Full technical documentation suite (currently being generated).
- **Agent Registry Wiring**: Linking all sub-agents (Routing, Community, Weather) to properly execute and pass telemetry back to the WorkflowManager.

## 3. Planned
- **Phase 3: Real AI Integration**: Replace `DummyMLPredictor` with an actual `.pkl` random forest/XGBoost model. Replace `DummyLLM` with the OpenAI/Anthropic SDK.
- **Phase 9: Profile Persistence Verification**: Connect the React `ProfilePage.tsx` to the `GET /api/v1/profile/` endpoint and verify preference writes.
- **WebSocket Frontend Binding**: Replace Axios `setTimeout` polling with true WebSocket consumption in `JourneyMonitor.tsx`.

## 4. Not Implemented
- **Vector Database**: Integration for RAG-based context parsing via Pinecone/Milvus.
- **OAuth2 / Social Login**: Real user authentication beyond mocked/stubbed JWT issuance.
- **Push Notifications**: FCM/APNs integration for mobile-client alerting when an anomaly enters the bounding box.
- **Real Maps API Key Integration**: Replacing the open-source dummy routes with true Mapbox/Google Maps routing profiles.

## 5. Unknown
- **Scalability Thresholds**: Unknown limits on `WorkflowManager` asynchronous DAG execution times when concurrent users scale past 1,000.
- **Rate Limits**: Open limits on LLM API consumption could cause cost-overruns if not mitigated by a caching layer.
