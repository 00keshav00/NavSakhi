# SafeShe Database Schema

SafeShe utilizes MongoDB via the asynchronous `motor` driver. Data is modeled in Python using Pydantic classes and standard Python Enums that inherit from `str`. The core schemas are located in `/app/models/`.

---

## 1. Collection: `journeys`

**Description**: Tracks the end-to-end lifecycle of a user's transit session, encompassing planning coordinates, AI-generated insights, and realtime state changes.

### Model Representation (`Journey` in `app/models/journey.py`)

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `id` | `PyObjectId` | No | Primary Key (`_id`). Auto-generated on insert. |
| `user_id` | `PyObjectId` | No | Foreign Key linking to `profiles`. |
| `source` | `str` | No | Starting coordinate string (`"lat,lng"`). |
| `destination` | `str` | No | Ending coordinate string (`"lat,lng"`). |
| `plan` | `JourneyPlan` | Yes | Nested object containing routing details. |
| `state` | `JourneyState` | No | Nested object containing active metrics and states. |
| `alerts` | `List[Alert]` | Yes | Array of triggered AI or emergency alerts. |
| `metadata` | `Dict` | Yes | Extensible metadata (device info, session tags). |

### Nested: `JourneyPlan`
| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `route_geometry` | `str` (GeoJSON)| Yes | Encoded Polyline or GeoJSON string defining the path. |
| `transport_mode` | `TransportMode`| No | Enum: `WALK`, `BICYCLE`, `BUS`, `SUBWAY`, `CAB`, `OWN_VEHICLE`. |
| `estimated_duration` | `int` | Yes | Duration in seconds. |
| `estimated_distance` | `int` | Yes | Distance in meters. |
| `safety_score` | `float` | Yes | Calculated ML score (0-100). |
| `weather_state` | `Dict` | Yes | Weather context at time of planning. |

### Nested: `JourneyState`
| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `current_state` | `JourneyStateEnum`| No | Enum: `PLANNED`, `ACTIVE`, `PAUSED`, `COMPLETED`, `CANCELLED`, `SOS`. |
| `started_at` | `datetime` | Yes | UTC timestamp. |
| `completed_at` | `datetime` | Yes | UTC timestamp. |
| `current_location` | `str` | Yes | Live polling coordinate (`"lat,lng"`). |

### Indexes
- `{ "user_id": 1 }`: Optimized for fetching journey history.
- `{ "state.current_state": 1 }`: Optimized for background workers polling `ACTIVE` journeys.

### Where Used
- **Repositories**: `JourneyRepository` (`app/repositories/journey_repo.py`)
- **Services**: `JourneyService` (`app/services/journey_service.py`)

## 2. Collection: `profiles` (Implied/Referenced)

**Description**: Stores user credentials, preferences, and emergency contacts.

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `_id` | `PyObjectId` | No | Primary Key. |
| `email` | `str` | No | Unique identifier. |
| `hashed_password`| `str` | No | Bcrypt hashed string. |
| `preferences` | `Dict` | Yes | User UI and routing preferences (e.g., "avoid dark areas"). |
| `emergency_contacts` | `List` | Yes | Array of phone numbers for SOS triggers. |

### Indexes
- `{ "email": 1 }`: Unique index.

---

## 3. Collection: `community_reports`

**Description**: Stores localized anomalies and dangers reported by users.

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `_id` | `PyObjectId` | No | Primary Key. |
| `user_id` | `PyObjectId` | No | Foreign Key to reporting user. |
| `location` | `str` (GeoJSON)| No | Point geometry indicating danger location. |
| `incident_type` | `str` | No | Type of danger (e.g., "Broken Streetlight", "Suspicious Activity"). |
| `severity` | `str` | No | `LOW`, `MEDIUM`, `HIGH`, `CRITICAL`. |
| `description` | `str` | Yes | Optional user-provided context. |
| `created_at` | `datetime` | No | Timestamp of submission. |

### Indexes
- `{ "location": "2dsphere" }`: Geo-spatial index for bounding box heatmap queries.
- `{ "created_at": 1 }`: TTL index (potentially) to expire stale reports.

### Where Used
- **Services**: `CommunityAgent` (queries nearby reports to affect journey `safety_score`).
- **Endpoints**: `GET /api/v1/community/heatmap`, `POST /api/v1/community/`.
