# SafeShe ML Pipeline

## Overview
SafeShe ML is a comprehensive geospatial data engineering and feature extraction pipeline designed to process raw urban data (OSM, Population GeoTIFFs, Crime CSVs) and deterministically engineer features related to urban safety, human activity, and isolation.

## System Requirements
- **OS:** Windows 10/11 (64-bit)
- **Python:** 3.10+
- **Compiler:** Microsoft Visual C++ 14.0 or greater (Desktop development with C++). **This is mandatory for compiling the pyrosm dependency.**

## Setup Instructions

### 1. Install Microsoft C++ Build Tools
Before running `pip install`, you **must** install the Microsoft C++ Build Tools:
1. Download [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/).
2. Run the installer and check the **Desktop development with C++** workload.
3. Install and reboot if necessary.

### 2. Install Python Dependencies
Open your terminal in the project root and run:
```bash
pip install -r requirements.txt
```

### 3. Prepare Raw Data
Ensure the following files exist in their respective directories:
- `ml/datasets/raw/osm/chennai_v1.osm.pbf` (The OSM extract)
- `ml/datasets/raw/population/population.tif` (Valid WorldPop GeoTIFF)
- `ml/datasets/raw/crime/*.csv` (Supported historical crime records)

### 4. Execute the Preflight Check
Verify your environment is sound before burning CPU cycles:
```bash
python ml/preflight/preflight_check.py
```

### 5. Run the Pipeline
Execute the main orchestrator. This will sequentially run all loaders, generators, feature engineers, validators, and labelers:
```bash
python ml/run_pipeline.py
```

### 6. Review Analytics
After the pipeline finishes, review the analytical output generated by the Dataset Profiler:
- Open `reports/dataset_profile.html` in your web browser.
